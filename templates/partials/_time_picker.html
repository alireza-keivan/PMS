{% load i18n %} {% comment %} Pick a time of day - the "Time Picker" card from the design handoff. Three little wheels side by side: hour, minute, and am/pm. The middle row of each is the chosen one; the rows above and below fade away. Minutes go in half-hour steps, so there are only two of them: 00 and 30. A row can be tapped, or the wheel spun - dragged with a finger or the mouse, rolled with a scroll wheel or trackpad (sideways as well as up and down), or turned with the arrow keys once the wheel has the focus. Reusable anywhere a form asks for a time: {% include "partials/_time_picker.html" with field=form.check_in_time %} Optional extras: step minutes between choices (default 30) picker_id only needed if the same field id could appear twice on a page How it works, and why it's built this way: the real time box is always here and always submitted. With no JavaScript it shows as the browser's own time box and the form works exactly as before. When the script does run it hides that box, shows the one field, and writes back into the same input (firing `change`, so anything listening on it still updates). The input stays the one source of truth; the wheels are only a nicer way to fill it in. {% endcomment %}
