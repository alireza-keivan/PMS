{% load i18n photo_extras %} {% comment %} The whole photo row for one villa or one room type: the pictures as they will really look on the villa page, each with its own remove and re-frame buttons, then a dashed tile that opens the file picker. Swapped in whole by HTMX after a picture is added, removed or re-framed, so it always shows what is really stored. Include with: photos - the pictures to show remove_url_name - which URL removes one of them villa - always category - only for a room type's pictures error - optional, something that went wrong while uploading Every tile is 16:9, not square, and shows the cropped copy - because 16:9 is what the public villa page shows. A square thumbnail here was quietly lying: an operator lined a photo up against this box and then found the top of it gone on the real page. Picking a file opens the framing window first (static/js/photo_cropper.js): the operator drags and zooms the picture inside a 16:9 frame, exactly the shape guests will see, and only then does it upload. The frame they chose rides along in the hidden "crops" box next to the file input. Uploading still happens there and then - the file has to go somewhere - but the picture is only held aside until the page is saved, and taking one off only marks it. Nothing on this row is real until Save is pressed; leaving the page instead puts everything back. See PhotoQuerySet in apps/villas/models.py. So a held-aside picture is drawn plainly as "Not saved yet" with its own Undo, rather than looking identical to the ones that are really there. Re-framing is the one thing here that does save straight away: it changes which part of one picture shows and nothing else on the page, so holding it back would mean a second set of staged fields for very little. The add tile is the one exception to uploading immediately: on a villa that doesn't exist yet (the very first step 1, before anything is saved) there is no row to attach a photo to, so the tile is a plain field that rides along with the whole form when it is submitted, and static/js/villa_form.js gives it a local preview so it doesn't look inert in the meantime. {% endcomment %} {% if error %}
